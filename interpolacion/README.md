# Práctica: Interpolación de Lagrange vs. Diferencias Divididas de Newton

**Asignatura:** Métodos Numéricos (SCC-1017)  
**Institución:** Instituto Tecnológico Superior de Xalapa (ITSX)

## Descripción del Proyecto
Este proyecto contiene la implementación en Java de los métodos numéricos de **Interpolación por Polinomios de Lagrange** y **Diferencias Divididas de Newton**, permitiendo la comparación de resultados y análisis numérico del polinomio interpolante.

## Requisitos del Entorno
* **Java Development Kit (JDK):** Versión 11 o superior.
* **IDE Recomendado:** NetBeans, IntelliJ IDEA, Eclipse o VS Code.
